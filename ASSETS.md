# Aset, sumber, dan data

- Ilustrasi Bio, Mesha, dan Prof. Nara di `assets/illustrated/` dibuat baru dengan ImageGen untuk proyek ini. Bio mengikuti referensi visual yang disediakan pemilik proyek. Foto/gambar referensi aslinya tidak dimasukkan ke paket GitHub.
- Atlas PNG dipakai melalui bagian gambar pada Canvas dan CSS. Catatan prompt terdapat di `assets/illustrated/GENERATION.md`.
- Peta, objek, dan efek grafis dibuat melalui `src/art.js`.
- Musik dan efek suara disintesis lokal melalui Web Audio API dalam `src/audio.js`. Tidak ada audio komersial atau rekaman paus asli.
- Bank 40 soal ditulis khusus untuk latihan kelas awal dan tersimpan pada `src/learning-data.js`.
- Fakta pendukung kasus paus merujuk pada NOAA Fisheries dan NOAA Ocean Service. Tautan bacaan ada di jurnal game. Data sensor dan eksperimen cerita merupakan simulasi.
- Game tidak meminta nama anak, akun, foto, atau lokasi. Tidak ada iklan, analitik, API key, atau backend aplikasi. Hosting GitHub Pages tetap tunduk pada kebijakan layanan hostingnya sendiri.
- Save disimpan pada localStorage browser. Tidak disertakan dalam repository maupun ZIP. Tautan bacaan eksternal hanya diakses jika pemain membukanya.

Pemilik proyek belum menetapkan lisensi publik untuk kode dan aset. Mengunggah repository tidak otomatis memberi lisensi penggunaan ulang; pemilik dapat menambahkan LICENSE sesuai pilihannya. Tidak ada klaim bahwa aset hasil generasi dijamin bebas dari seluruh hak pihak lain.
